# Stacks Folio

Your on-chain portfolio tracker for the Stacks Bitcoin Layer.

Connect your Leather wallet to instantly see:
- STX balance + USD value
- Stacking status & locked amount
- Last 20 transactions with Hiro Explorer links
- NFTs held in your wallet
- BNS name (.btc)

Built for the Stacks Builder Rewards March challenge.

## Stack
- React + Vite + TypeScript + Tailwind
- @stacks/connect v8 for wallet connection
- Hiro API for on-chain data (no API key needed)
- CoinGecko for live STX price

## Run locally
```bash
npm install
npm run dev
```

## Deploy
Push to GitHub, connect to Vercel. Done.
